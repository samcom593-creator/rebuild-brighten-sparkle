# Skool Course Blueprint

The detailed classroom map remains in `docs/skool-classroom-spec.md`. This rebuild treats Skool as a linked learning destination with explicit capability state, not as an undocumented browser automation target.

## Website boundary

- Resources is the canonical entry point.
- Existing course/training deep links redirect with a concise migration notice.
- Website records enrollment/readiness/reference state only when a verified integration supplies it.
- A missing write API produces a manual action with a direct authorized link; it never reports a post, enrollment, or completion that did not occur.

## Course structure

Keep the approved Welcome Aboard path, licensed/unlicensed split, contracting setup, sales fundamentals, compliance, first-week launch, and 30/60/90 growth milestones. Each item needs owner, objective, source URL, audience, prerequisite, completion evidence, and review date. Do not duplicate copyrighted course content into the website.

## Acceptance

Validate destination links, role visibility, mobile labels, empty/error state, and capability copy. Production posting or enrollment requires a documented API, scoped credential, audit receipt, and owner-approved smoke test.
